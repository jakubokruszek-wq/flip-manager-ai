This release adds a separately consented detail stage rather than another change to feed selectors or scrolling.

In Offers, Uzupełnij do ręcznego sprawdzenia builds a queue only from the current RAM review rows with exact canonical links to the approved group, deduplicated and capped20. New one-time consent covers up to3 minutes, sequential foreground page loads, DOM/embedded page data only, and no response-body inspection or interaction with reactions/comments/forms/shares. It does not reuse desktop/scan grants, reset scan limits or run automatically after installation.

A temporary visible GeckoSession shares the existing runtime's ordinary profile. The original group session is detached/inactive during review and restored afterward; ordinary group navigation/scroll implementation is unchanged. Native gate accepts only the current target post of the exact group, at most4 same-ID navigation requests and10s to load per target. Other group/unverified aliases, login/checkpoint/CAPTCHA, popup/user navigation, lost focus/port/engine, deadline or pause abort the stage. No aliases are inferred from a redirect. Abort publishes no partial business rows; temporary session closes in finally. No programmatic login/cookie access.

Reader requires a fresh per-document nonce, exact current permalink and confirmed same-ID self link in a non-comment card or exact same-ID embedded record. URL alone cannot promote arbitrary suggested content. A unique same-post dialog/main region can supply message markers outside a header article if its post links contain no other post/group. Text traversal prunes comments, quotes, forms, controls and independent cards instead of rejecting an entire message merely because comments are nested beneath it. Input values are never read. Comment/reply permalinks cannot bind a main card. Same-ID representations merge through the existing field/conflict rules. Competing messages stay ambiguous; only the requested ID returns.

Results distinguish opened pages, bound identity, text read, fields added/promoted, unchanged fields, unresolved read and excluded classification. Missing read is never reported as proof of no data. Selected fields remain RAM-only and clear on pause/context loss; a separate store persists bounded status/counts only, leaving desktop/offline histories/outbox/receipts intact. Existing external Open post action remains available unchanged. No OCR, new photo work, production collector/upload/LIVE, merge or deployment.
