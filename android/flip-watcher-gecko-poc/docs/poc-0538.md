The normal desktop preview temporarily changes that original to desktop and restores mobile afterwards; a subsequent detail batch could therefore run in mobile. The existing native review test initialized the original session as desktop and missed this discrepancy.

The temporary review session now explicitly uses standard Gecko desktop UA and desktop viewport, leaving the original session unchanged. The content reader independently checks interactive/complete before reading or capturing. It no longer requires the whole page's media load to finish. Readiness expiry reports LOCATION_TIMEOUT, PORT_TIMEOUT, FOCUS_TIMEOUT or DOM_TIMEOUT according to the unfulfilled gate, instead of collapsing them into PAGE_TIMEOUT. The strict decoder still accepts old count-only OCR summaries and rejects malformed nested summaries. Cancel/pause also retains only bounded numeric stop evidence.

A JVM test covers exact underlying failure round-trip, old-history compatibility and rejecting a successful nested failure.
