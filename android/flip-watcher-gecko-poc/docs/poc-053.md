## Functional changes

Scroll discovery no longer relies on eight ancestors of articles and named feeds.
It samples five viewport points and the top/bottom three hit-test layers, follows
at most 32 ancestors, and caps the candidate set at 512 nodes. Actual scrollability,
visible geometry, same document, approved context and containing a top-level article
remain mandatory for an inner scroller. Dialogs/comments/hidden/clipped/unbound
containers remain excluded. No arbitrary clicks, synthetic gestures, iframe access,
CSS override, forced scrolling or native bridge. Public Gecko scrollBy only scrolls
the document; it was not introduced as a pretend fix for unknown inner scrolling.

The same bounded scroll loop now receives an actual anonymous/deep scroll target.
Five attempts, original 60s deadline, original consent and STOP behavior remain.
Count-only maxima describe examined nodes and rejection categories (range, hidden/
forbidden, offscreen, unbound), hit layers and chosen root/inner type. These are
container observations, not posts; categories/maxima across passes are not additive.
No selectors, DOM dumps, attribute values, URLs or text are exported in this evidence.
If no target exists or all targets fail the guards, 0/0 is still reported honestly.

Each accepted identity carries one fixed qualification enum: CANDIDATE, NO_TEXT,
FOREIGN_CITY, NOT_PROPERTY, INTENT, MISSING_FIELDS, CONFLICT or CLASSIFIER. The codes
are derived from existing pinned pure field/intent/location rules; upstream files
and collector core remain unchanged. Empty observations do not overwrite useful
qualification. Conflicting concrete intents remain unusable; uncertain combined
classifications are explicitly generic rather than invented. Field conflicts retain
the existing conservative behavior. Filters/ID checks are not weakened.

The local result shows a reason and available selected numeric fields for EACH
excluded post: missing bound text, recognized buy/rental/service intent, another
city, no recognized property signals, no price/area/rooms, conflicting intents, or
an explicitly unresolved classifier/locality reason. This is not a new raw-text
viewer. Candidate cards stay first. Exact identities and fields/reasons stay RAM-only;
clipboard/history still contain aggregate status/counts. Pause/context STOP clears
all details. Old 22-counter summary records remain readable without mutation, while
new live messages must carry the complete strict current schema. No old consent reuse.
