# Gecko POC 0.2.5 — lokalna diagnostyka widocznych postów

Status: CONDITIONAL GO do ręcznego eksperymentu DOM, po NOWEJ zgodzie operatora. Skuteczność na prawdziwym Facebooku pozostaje niepotwierdzona. Wynik 0.2.4 (115 żądań, brak dokładnych ID) nie jest wynikiem tej wersji. Liczniki sieciowe pozostają NO_GO jako samodzielna architektura kolektora.

## Instalacja na Samsungu bez komputera
1. W GitHub Actions otwórz najnowszy zielony run „Android Flip Watcher Gecko POC” dla PR #45. Pobierz artefakt `flip-watcher-gecko-poc-arm64-*`, rozpakuj ZIP w Moich plikach i otwórz APK.
2. Sprawdź wersję 0.2.5 i versionCode > 90. Pakiet pozostaje `pl.jakubokruszek.flipwatcher.geckopoc`; podpis SHA-256 `878b11e677eb4a62883b0b8709fa19c969926708053a01d47f01b0548fb370a2` jest taki sam jak wcześniej. Aktualizacja zachowuje sesję. Przy błędzie podpisu przerwij — NIE odinstalowuj poprzedniej aplikacji i nie kasuj danych.
3. Samo zainstalowanie APK nie zezwala na test prawdziwej grupy. Wymagana jest nowa decyzja właściciela, a następnie oddzielna zgoda w aplikacji.

## Próba na ekranie włączonym (dopiero po zgodzie)
1. Otwórz istniejącą sesję i zatwierdzoną grupę `lodzsprzedazzakupwynajem`. Logowanie wyłącznie ręczne. Poczekaj na zakończenie ładowania.
2. Nie wybieraj przycisków skanowania. Wybierz „Sprawdź widoczne posty”, przeczytaj zakres i wyraźnie zatwierdź jednorazową zgodę. Anulowanie ma dać brak odczytu.
3. Raport zawiera tylko liczby: kandydaci semantyczni i heurystyczni, dostępne linki, permalinki, unikalne dokładne ID oraz kandydaci pól ceny, powierzchni, pokoi, dzielnicy i zdjęć. ID wyłącznie z dokładnych linków tej grupy; brak ID pozostaje zerem. Same liczby nie potwierdzają poprawności ofert.
4. Po ręcznym przewinięciu można wykonać kolejną próbę, ponownie wyrażając zgodę. Diagnostyka sama nie przewija, nie klika, nie uruchamia skanu ani kolektora.
5. Zmień stronę lub zamknij sesję: wynik powinien zniknąć. LOGIN/CAPTCHA/CHECKPOINT, ukrycie dokumentu i utrata portu zatrzymują diagnostykę. Nie rozwiązuj zabezpieczeń automatycznie.

## Wygaszenie ekranu
Ta funkcja wymaga widocznego dokumentu. Wygaszenie / przejście aplikacji w tło ma unieważnić wynik i zgodę. Po powrocie wymagana jest nowa próba i nowa zgoda. Nie stwierdzamy działania diagnostyki ani kolektora przy zablokowanym ekranie.

## Prywatność i ograniczenia
Wynik wyłącznie w RAM i na ekranie, bez pliku, outboxa, logcat ani wysyłki. Tekst widocznych kart jest przetwarzany chwilowo w skrypcie i nie opuszcza DOM jako treść. Brak odczytu formularzy, cookies, tokenów i odpowiedzi sieciowych. Dotychczasowa sesja przeglądarki zachowuje swoje cookies jak wcześniej.

Maksymalnie 20 kandydatów; kontenery mobilne są heurystyczne, mogą pomijać posty lub dzielić jedną ofertę. Pola są sygnałami tekstowymi, bez potwierdzenia ceny/metrażu. Brak OCR, iframe, shadow DOM, odczytu skryptów strony i zgadywania identyfikatorów. Kontekst ograniczony do dokładnej zatwierdzonej ścieżki, bez parametrów i fragmentów; przekierowanie do innego identyfikatora wymaga osobnej decyzji.

GO dla dalszej integracji kolektora wymaga niezależnego potwierdzenia na Samsungu, że prawdziwy DOM zawiera poprawne karty i dokładne identyfikatory. Jeśli są tylko heurystyczne karty/pola, wynik to CONDITIONAL GO dla diagnostyki; jeśli nie ma użytecznych kandydatów ani ID — NO_GO dla tej metody. Żaden wynik nie zezwala automatycznie na LIVE.
