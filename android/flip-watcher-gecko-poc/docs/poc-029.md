# Gecko POC 0.2.9 — osobna, lokalna diagnostyka odpowiedzi

Kontynuacja PR #45 od `79d7510516e933b6a680919431f38402fec25402` (0.2.8), bez main/merge/deploymentu. Operator upoważnił przygotowanie tej ścieżki po wynikach DOM 0.2.8: 12 bloków mobilnych, brak linków/ID oraz jawnych wartości atrybutów. Wcześniejsze ograniczenie do DOM nie jest traktowane jako zgoda na odczyt sieci: nowy przycisk wymaga osobnej, wyraźnej zgody przy KAŻDEJ próbie.

## Dlaczego rozwiązanie z rozszerzenia

Rozszerzenie komputerowe nie polega wyłącznie na DOM. `network-hook.js` przechwytuje fetch/XHR i przekazuje treść do `collector-core.extractStructuredRecordsFromText`. POC reużywa ten sam, niezmieniony parser (SHA-256 kontrolowany podczas budowania), lecz transport adaptuje do oficjalnego API Firefox `webRequest.filterResponseData`. Nie kopiuje galerii, buforów rekordów ani publikowania danych na stronie.

Źródło API: https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/webRequest/filterResponseData
MV2 wymaga `webRequestBlocking` i istniejących uprawnień hostów. Brak nowych domen, storage/cookies/headers, obejść zabezpieczeń lub zmiany User-Agent. Niedostępne API daje `UNSUPPORTED`; nie ma ukrytego fallbacku. Obsługa API przez Firefox Android nie jest dowodem działania na danym Samsungu.

## Granice

- Domyślnie nieaktywne. Przycisk **Sprawdź dane sieciowe** i **Zgadzam się jednorazowo**. Dawna zgoda/limit skanu pozostają bez zmian.
- Jedna karta, top-frame, dokładny adres zatwierdzonej grupy, dokument widoczny i aktywny viewport. Bez aliasów grupy. Inne karty/iframe i niezatwierdzone dokumenty odrzucane.
- Do 15 s, 8 odpowiedzi, 4 jednoczesne strumienie, 512 KiB/odpowiedź, 2 MiB łącznie, 20 unikalnych ID. Wyłącznie XHR/fetch do `/ajax/`, `/api/graphql`, `/graphql` na trzech hostach Facebooka. Nie odczytuje cookies, nagłówków, request body, multimediów ani danych CDN.
- Oryginalne bajty przekazywane najpierw do strony; brak modyfikacji. Na końcu strumień zamykany, przy STOP/limicie odłączany, bufory czyszczone. Tylko ograniczona pamięć RAM; JavaScript nie gwarantuje kryptograficznego wyzerowania pamięci silnika.
- Parser wymaga dokładnego ID oraz rzeczywistego permalinku tej grupy; dodatkowa niezależna walidacja jawnych pól `url`/`permalink`/`permalink_url` nie pozwala uzupełnić grupy z kontekstu (do 400 pól, 4096 znaków na URL, do 20 ID linków); gołe ID, photo fbid i obce grupy nie są awansowane. Nie zgaduje ID z markerów. Pole ceny/metrażu to heurystyczny sygnał w tekście przypisanym przez parser; nie potwierdzenie poprawności/kompletności oferty. Zdjęcia to obecność metadanych, bez ich pobierania.
- Do Androida trafiają wyłącznie allowlistowane, ograniczone liczniki. Bez tekstów, nazw, URL, ID, tokenów, plików/logcat, uploadu i backendu. Surowa odpowiedź istnieje tylko przejściowo w RAM parsera; nie jest zapisywana.
- LOGIN/CAPTCHA/CHECKPOINT, zmiana grupy/strony, nawigacja, ukrycie, pauza aplikacji, zamknięcie sesji/portu: STOP, czyszczenie. Nie potwierdzamy pracy pod blokadą; ta diagnostyka ma się zatrzymać.
- Nie uruchamia skanu, kolektora, automatycznego przewijania, kliknięć, uploadu ani LIVE. Stare pomiary liczników i DOM zachowują własny zakres (raport DOM nadal 0.2.8).

## Samsung: instalacja i oddzielna próba operatora

1. Pobierz arm64 ZIP z Actions podanym w PR. Rozpakuj w „Moich plikach” i otwórz APK. Zainstaluj jako **aktualizację**, bez odinstalowywania/kasowania danych. Ten sam pakiet i stały publiczny klucz debug (SHA-256 `878b11e677eb4a62883b0b8709fa19c969926708053a01d47f01b0548fb370a2`), versionCode większy niż 812. Konflikt podpisu: przerwij instalację, nie usuwaj aplikacji.
2. Dopiero operator decyduje o realnej próbie. Przy włączonym ekranie otwórz zatwierdzoną grupę, poczekaj na 100%, poprawny tytuł i port rozszerzenia. Nie wybieraj dawnego skanu; jego limit nie jest resetowany.
3. **Sprawdź dane sieciowe**, przeczytaj osobną zgodę, zatwierdź jednorazowo. W 15 s możesz ręcznie przewinąć feed, żeby strona sama zażądała danych. Nie odświeżaj/nawiguj podczas próby: przerywa to pomiar.
4. Udostępnij wyłącznie raport `ODPOWIEDZI 0.2.9`, bez treści strony. `responseApiAvailable=1`, `responseArmed=1`, `responseFiltered/Completed/Bytes>0` potwierdzają ścieżkę transportu; `responseExactIds>0` dopiero potwierdza dokładne identyfikatory parsera. Klucze `responseKey*` to obecność nazw kluczy, nie potwierdzone ID.
5. Jeżeli `RequestsSeen>0`, ale `OriginRejected>0` i `Filtered=0`, brak bezpiecznego powiązania z dokumentem; nie poszerzamy go automatycznie. `Oversize/DecodeErrors/StreamErrors` wyjaśniają ograniczenia. Zera nie dowodzą braku postów.
6. Oddzielna próba przerwania: nowa zgoda, po 2 s wygaszenie ekranu. Po powrocie wynik ma być wyczyszczony, bez wznowienia; kolejne uruchomienie wymaga nowej zgody. To test STOP, nie działania w tle. Analogicznie przejście poza grupę lub zamknięcie sesji.
