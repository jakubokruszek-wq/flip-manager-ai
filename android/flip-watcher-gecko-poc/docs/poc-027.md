# Gecko POC 0.2.7 — kontenery otaczające widoczny tekst

Pomiar Samsunga 0.2.6: 6 mobileTextBlocks, 6 kandydatów heurystycznych, 1 sygnał metrażu, 0 linków i dokładnych ID. Potwierdza dostęp do tekstu, nie tożsamość postów.

## Zakres
Ta sama funkcja „Sprawdź widoczne posty”, nowa jednorazowa zgoda opisująca także kontenery. Do 20 bloków startowych; maksymalnie sześć poziomów rodziców (do 120 unikalnych kontenerów). Bez klikania, przewijania, skanu i kolektora. Parser linków nadal niezmieniony, wspólny z rozszerzeniem.

Zatrzymanie przed body/html/main, role=feed/main/navigation i pagelet Feed. Kontenery zawierające kilka rozpoznanych widocznych bloków są wspólne; kontenery z kilkoma ID są niejednoznaczne. Kontenery z linkami postów obcej grupy są odrzucane. Każdy taki kontener jest liczony osobno, bez przypisywania zdjęć, ceny czy ID do jednego bloku; przechodzenie dalej w górę zostaje przerwane. To konserwatywne: kilka akapitów jednego posta też może zostać oznaczone jako wspólne.

## Nowe liczniki
- ancestorContainers: unikalne zbadane kontenery, bez korzenia/feedu.
- ancestorWithLinks, ancestorWithExactId, ancestorWithPhotos: kontenery nieshared, bez sprzecznych ID i obcej grupy, z odpowiednio widocznymi linkami / jednym dokładnym ID tej grupy / elementem img.
- ancestorExactAndPhoto: te same warunki, jednocześnie dokładny link i img. Nadal nie dowodzi powiązania zdjęcia z ofertą; obraz może być awatarem.
- ancestorWithPrice, ancestorWithArea: heurystyczne sygnały pól w takich kontenerach, bez zapisu wartości.
- ancestorSharedContainers, ancestorAmbiguousContainers, ancestorForeignContainers: odmowa przypisania do jednego bloku.
- ancestorFeedStops, ancestorDepthStops, ancestorMaxDepth: ograniczenia przejścia.

**Liczniki dotyczą kontenerów, nie postów. Nie sumować poziomów jako liczby ofert.** ancestorWithExactId nie podnosi confirmedIds: to tylko obserwacja linku w rodzicu, bez potwierdzenia własności. Pierwotne liczniki bloków i ich ID pozostają osobne. Referencje DOM, teksty, linki i ID są chwilowe w JS; do Androida przechodzą wyłącznie liczby. Brak zapisu plików, logcat, uploadu, response bodies, formularzy i cookies. Reguły STOP, widoczny ekran i dokładna zatwierdzona grupa pozostają wymagane.

## Instalacja i próba
Pobierz arm64 APK 0.2.7 z najnowszego zielonego CI wskazanego w PR #45. Ten sam pakiet i podpis, wyższy versionCode. Instaluj jako aktualizację. Nie odinstalowuj aplikacji, nie kasuj sesji ani nie resetuj limitu dawnego skanu.

Na włączonym ekranie pokaż jeden post, wybierz „Sprawdź widoczne posty”, przeczytaj i zaakceptuj nową zgodę. Prześlij wyłącznie raport liczbowy DOM 0.2.7. Nie wybieraj przycisków skanowania. Zmiana grupy/strony, LOGIN/CAPTCHA/CHECKPOINT, utrata portu lub wygaszenie/tło mają zatrzymać diagnostykę i usunąć wynik.

Status: CONDITIONAL GO do lokalnego eksperymentu. Bez testu fizycznego 0.2.7 i bez potwierdzenia poprawnej tożsamości oraz deduplikacji pozostaje NO_GO do podłączenia kolektora/LIVE. Desktopowy odczyt odpowiedzi sieciowych nadal nie jest przenoszony.
