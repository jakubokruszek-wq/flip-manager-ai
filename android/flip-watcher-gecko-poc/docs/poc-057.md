# Gecko POC 0.5.7 — bounded viewport-tail alignment

Physical Samsung 0.5.6: 30 s, four moves, 25 no-target waits, one exhausted inner
container, four exact IDs/two eligible offers, no transport budget/error issue.
This proves finite inner extent, not completeness or the visibility of the last
post in the actual viewport. The specific Facebook pagination cause is unknown.
The desktop extension uses root/feed extent; mobile desktop layout adds clipped
ancestor and focus considerations, which the previous lazy-feed fixture omitted.

The same freshly consented preview now explicitly focuses/activates the actual
Gecko session using ordinary Gecko APIs and requests view focus. No spoofed
visibility/focus getters, wheel/touch/click events, native gestures or request
replays. Foreground cancellation remains authoritative.

After two no-target iterations, at most twice with >=5 s cooldown, the extension
may call scrollIntoView(end/nearest/instant) on the final top-level article ONLY
when it is below the actual visual viewport and contains exactly one approved
group post identity. It rejects foreign/ambiguous/unbound/detached/other-document/
dialog/comment/horizontally offscreen targets. It revalidates target identity after
awaiting privileged context. Already visible cards are not aligned again. Only
normal DOM ancestor scrolling occurs; no DOM/CSS modifications on Facebook.

These attempts count within the SAME 30 total attempts/30 s and original shared
60 s, never extending the deadline or resetting 20 retained IDs/64 responses/
4 MiB aggregate. Only measured ancestor/window downward scroll counts as movement;
layout change alone or a no-op is not progress. A successful alignment does not
prove a new offer or full feed. No repeated up/down recovery or clicks.

Four aggregate-only fields append the existing schema: scrollTailAttempts (0..2),
scrollTailMoves (bounded by attempts and total measured moves), pageFocused and
pageVisible (0/1: observed during the window). Old 22/30/34-field summaries are
readable without writeback. No text, ID, cookies/token persistence or upload.
Existing Oferty links, pause/context/port cleanup and production isolation remain.
Fresh consent explicitly describes the two bounded tail alignments. No new button.

Node regressions cover actual ancestor movement, two no-op attempts, refusal of
foreign/multiple/unbound/dialog/detached/offscreen/already visible cards, binding
change during async context verification, and numeric focus/visibility. Existing
extent/duration/lazy growth/privacy regressions retained. JVM bounds/history tests
added. Real Gecko acceptance retains previous finite/lazy and root tests, then
loads a clipped overflow-hidden viewport fixture: normal inner scrolling alone
cannot expose its exact last post; after alignment, and only then, the fixture
