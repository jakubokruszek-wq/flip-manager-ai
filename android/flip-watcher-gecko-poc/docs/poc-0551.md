# Gecko POC 0.5.51

Phone 0.5.50 completed all 13 detail openings, confirmed 13 identities, read 10 texts and closed 13 workers. Its OCR saw only two images / one text / no field suggestions. Single-post worker scheduling remains unchanged.

The data reader can establish a Story from embedded JSON while no DOM card has a clean permalink. The image reader previously required a separate DOM card/canonical proof, so structured-bound posts were skipped. The existing bounded streaming selector now optionally retains at most 20 own Photo image sources in document-local WeakMap memory, separately from text projections/native rows/reports. Full JSON validity, actual numeric Story identity and actual same-group permalink remain mandatory. No large JSON AST is built. Existing source, depth, work-time and object limits remain.

Only URI plus dimensions under an image field below a typed Photo is eligible. Comments, feedback, shared/quoted/foreign stories, actor/profile/avatar/video/caption paths and conflicting/late ancestor identities are excluded. HTTPS fbcdn.net subdomains only, no credentials/port/fragment. No URL or image is fetched or exported. Proofs are document/group/post/URL scoped and replaced by each successful reader attempt; source lists are immutable and capped.

For structured-only identity, the image reader requires an exact currentSrc/src match to this proof, a connected eligible article, no foreign ancestor post links, one unambiguous matching article, a loaded visible image and the existing geometry/occlusion/two-phase viewport proof. Signed query differences are not normalized away. No arbitrary primary card or URL-only document identity is introduced. No whole-card OCR or screenshot retention.

Lazy images may be scrolled into view and awaited up to three 250-ms checks after the initial 250-ms stabilization; the native seven-second request bound remains. No extra media fetch/click/navigation is made. Images without typed Photo evidence or without rendered IMG remain unsupported; no absence claim follows. Global 20-image, foreground and three-minute queue limits, original session, fresh consent, pause/unsafe-failure clearing and separate heuristic OCR fields remain unchanged.

Combined OCR report now includes actual text-data enrichment counts so zero OCR suggestions does not hide recovered fields. Cache-only OCR report/history schemas unchanged.

Validation: existing parser tests plus new source-ownership and end-to-end structured identity -> exact rendered image -> crop/commit fixtures. Negative cases include comments, foreign post/parent, ambiguous duplicate cards, changed source/query, unloaded/replaced media, malformed/truncated JSON, type/dimension/CDN violations and document scope. Native long emulator execution intentionally skipped per user preference; no real Facebook test by agent.
